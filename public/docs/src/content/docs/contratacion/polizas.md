Registra la **aprobación de pólizas** de cada contrato.

## Campos

- **Consecutivo, Fecha.**
- **Contrato:** referencia en texto (ej. `468 de 2025`). El sistema intenta
  **vincularlo** al contrato registrado (por número + año); si lo logra, se
  marca con un ícono de enlace.
- **Estado:** libre (ej. INICIO, ADICIÓN, PRÓRROGA, FINAL, RECIBO FINAL…), con
  color según el tipo.
- **Dependencia** y **Quién proyecta / aprueba**.

## Registrar

1. Menú → **Contratación → Aprobación de Pólizas → Crear**.
2. Complete el contrato, estado, dependencia y aprobador.

## Tabla y filtros

- Badge de estado por color.
- Columna "Vinc." indica si la póliza quedó enlazada a un contrato del sistema.
- Filtros arriba: estado (dinámico), dependencia, aprobó.
